## Onboarding Goals
1. User creates their first Space and understands what it represents
2. User adds at least one child to the Space
3. User logs their first entry
4. User understands the acknowledgment system
5. User feels: "this is organized, calm, and I'm covered"

---

## Critical Design Decision: Inclusive First Step
**Do NOT ask "Who is your co-parent?"**
Ask: "Who shares responsibility for a child with you?"
Options: Partner, Ex-partner, Grandparent, Guardian, Other family member, I'm the sole caregiver right now

This sets the inclusive tone immediately.

---

## Flow (Draft)

```
Welcome → Family Structure → Create Space → Add Child → First Entry → Invite (optional) → Home
```

### Screen 1: Welcome
- Tagline: "Two homes. One childhood."
- CTA: Get Started

### Screen 2: Family Structure
- "How would you describe your situation?"
- Non-judgmental options that serve all 5 personas

### Screen 3: Create Space
- Name your care arrangement
- Pick emoji/color

### Screen 4: Add Child
- Child name + date of birth

### Screen 5: First Entry (guided)
- "Log your first care record"
- Suggested: expense or event

### Screen 6: Invite (optional)
- "Want to invite [co-parent/guardian/member]?"
- Skip available

---

## Skip Options
- Invite step is skippable — solo use is valid
- First entry can be deferred — show empty state with prompt
