## Summary: Nookbud's Unique Feature Advantages

Nookbud is the only product in the market that combines all of the following:

1. **Spaces model** — multiple care arrangements per user, each with its own members, timeline, and records
2. **Role-based access** — owner, editor, viewer roles for any family member or professional
3. **SHA-256 file integrity** — every uploaded file is cryptographically hashed at upload
4. **Immutable version-diffed entries** — every edit to any entry type creates a new version with full diff history
5. **Structured acknowledgment + dispute layer** — per-entry acknowledgment and formal dispute capture
6. **Verified evidence bundle** — PDF + JSON + attachments + hash manifest for any professional
7. **Dedicated Resources layer** — categorized reference documents separate from timeline events
8. **Inclusive onboarding** — designed for any family structure, not just divorced parents
9. **One subscription covers the family** — invited co-parents join free

No single competitor offers more than 1-2 of these features. Most offer none.
